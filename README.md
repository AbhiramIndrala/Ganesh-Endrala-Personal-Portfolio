# Ganesh Endrala — Video Editor & Thumbnail Designer

A responsive, cinematic portfolio website showcasing video editing projects and thumbnail designs.

## Publish on GitHub Pages

1. Extract the ZIP.
2. Open the `ganesh_endrala_portfolio` folder.
3. Upload **the contents of this folder** to the root of your GitHub repository (not the folder itself).
4. Ensure `index.html` is at the repository root and the `assets/` folder is alongside it.
5. In GitHub, go to **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch `main` and folder `/ (root)`, then save.
8. Wait for the Pages deployment to finish and open the URL shown in the Pages settings.

## Included

- 20 video portfolio projects across 8 categories
- 25 thumbnail designs, with show-more and lightbox preview
- Responsive layouts for desktop, laptop, tablet, and mobile
- Mobile navigation, scroll animations, progress indicator, and reduced-motion support
- Banna.js animated cursor (pink, purple, and blue) with its visible control/credit bar disabled
- Phone and email links

## Contact form setup

The contact form currently contains a Formspree placeholder (`YOUR_FORMSPREE_ID`). It will not send enquiries until you create a Formspree form and replace the placeholder with your form ID. Until then, visitors can contact Ganesh using the phone and email links shown on the site.

## External dependencies

Google Fonts and Banna.js are loaded from external CDNs. Video previews and their thumbnails are hosted on Google Drive. The Google Drive items must be shared so viewers can access them (typically “Anyone with the link” set to Viewer).

## QA notes

Static HTML, CSS, JavaScript syntax, local asset references, category filters, project IDs, thumbnail references, and ZIP integrity were checked. This package has not been certified through physical-device or live-browser testing in this environment.
